# Minecraftで生活する — ESI-04 0.4.4 / Fabric 1.21.11

ESIの人格・会話・記憶を引き継ぎ、Minecraftのワールドに独立したプレイヤーとして参加させる。現在のプラグインは、MinecraftとESIを**同じPC**で実行する構成に対応する。シングルプレイではMODを導入したFabricでワールドを開く。専用サーバーでは、そのサーバーとESIを同じPCで実行し、サーバー側にもMODを導入する。

## 最初の導入

1. ESIを0.4.4へ更新する。既存の `data`・`models`・Python環境・AivisSpeechは残す。
2. Minecraft Java版 **1.21.11** をFabric Loaderで起動できるようにする。1.21.1とは別の版。動作確認時のLoaderは0.19.5、Javaは21。
3. Minecraftの、その起動構成の `mods` フォルダーへ、次の3つを入れる。別バージョンの同じMODを重複して入れない。

| ファイル | 入手先 |
| --- | --- |
| `esi-minecraft-bridge-0.4.4.jar` | このZIPの `plugins/minecraft/release` フォルダー |
| Fabric API **0.141.6+1.21.11** | [Fabric APIの配布ページ](https://modrinth.com/mod/fabric-api/versions?g=1.21.11) |
| Carpet **1.4.194 / Minecraft 1.21.11** | [Carpetの配布ページ](https://modrinth.com/mod/carpet/version/HzPcczDK) |

JARは展開しない。ESI BridgeはCarpetの仮想プレイヤー機能を使う。Minecraft本体・Fabric・依存MODはESIのPython環境とは別に導入する。依存ファイルの正確なURL・ハッシュは `plugins/minecraft/dependencies.json` に記録している。

WindowsではZIPの **`Minecraft連携MODを準備.cmd`** を開くと、依存MODを取得し、SHA-256を確認して、`plugins/minecraft/release/mods` に必要な3つのJARをそろえる。そのフォルダーが開いたら、中の3つをMinecraft側の `mods` へコピーすればよい。Fabric Loader自体の導入は先に行う。

## ワールドへ接続する

1. Fabricでワールドに入り、チャットへ **`/esi link`** と入力する。シングルプレイでもこの接続コマンドを使える。
2. 自分に表示された接続先URLと接続コードを確認する。コードのメッセージはクリックでコピーできる。接続先は通常 `http://127.0.0.1:8766`。そのポートが使用中なら8767〜8775を使うので、表示されたURLを指定する。
3. ESI本体を開始し、「プラグイン・Minecraft」タブを開く。Minecraftを選び、接続先とコードを貼り付け、「ワールドに接続してESIを参加させる」を押す。
4. Minecraftを一時停止している場合は再開する。ESIが `ESI_…` という別プレイヤーとして参加する。初参加は利用者の近く、次回からはそのESIが前回いた場所に戻る。
5. 満腹度・体力・所持品・見えている周囲が表示されたら接続完了。まず「選んだ操作を1回試す」で動作を確認できる。
6. 目標を書き、「Minecraftで自分から行動を選ぶ」にチェックし、「目標と自律活動の設定を適用」を押す。

開始直後の自律活動はOFF。再起動しても接続や行動を勝手に再開しない。「このPCに接続先・コードを保存する」は任意で、セーブDBと診断にはコードを入れない。`/esi link` をやり直すとコードが変わる。

## 最初に試すこと

- ESIの近くへパンと木のツルハシを投げる。目標を「近くに落ちているアイテムを拾って、周りを調べてみて」にする。自分の所持品に増えたかを確認する。
- 近くのブロックを対象に「持っているツルハシで、近くに見えている石を一つ採掘して」と頼む。ESIが道具を選び、採掘にかかる時間を経てブロックが変わる。落ちた物を拾うことは別の行動。
- 満腹度が減り、食べ物を持っている時に「持っているパンを食べて」と頼む。食べ物の数と満腹度を確認する。満腹なら通常のパンは食べられない。
- 「今、何が見える？」「何を持っている？」「体調はどう？」と話す。現在のMODの観察から答える。切断中は現在の状態が分からないと伝える。

会話での「掘って」「食べて」「集めて」などは目標へ反映する。目標を頼むだけではOFFの自律活動をONにしない。OFFの時は画面の設定を適用して開始する。

小型の言語モデルが手順を飛ばす場合は、「木のツルハシを手に持って」と一つの操作を先に教え、所持品の選択が変わってから「今持っている道具で石を一つ採掘して」と頼む。ブロックが壊れただけで、適した道具を使った・アイテムを得たと判断しない。手動の操作一覧でも持ち替えと採掘をそれぞれ確かめられる。

最初から所持品や満腹度を補充するESI用の処理は入れていない。採掘・食事・拾得・道具の耐久度はMinecraftの通常の仕組みを使う。難易度やゲームルールによる回復・死亡・ドロップは、そのワールドの設定に従う。

## 停止と切り替え

| 操作 | 結果 |
| --- | --- |
| ESIの「行動を停止」／「操作を止めて」と話す | 現在の操作と自律活動を止める。プレイヤーは残る |
| ワールド内の `/esi stop` | Minecraft側で以後の操作も停止する。再開時はESIで再接続する |
| ESIの「切断」／ワールド内の `/esi disconnect` | ESIプレイヤーを退出させる |
| 利用者がワールドから退出 | ESIも退出する |
| ESIとの通信が約30秒途切れる | 操作を止め、ESIを退出させる |
| ESIの「仮想の部屋へ戻る」 | Minecraft接続を終了し、保存していた仮想の部屋・身体へ戻る |

Minecraft側で停止・退出した後、再接続するまでは自律活動を開始できない。ESCメニューなどでワールドが停止すると接続処理も進まない。再開してから接続する。接続できない時は同じワールドで `/esi link` をやり直し、表示されたURLと新しいコードを使う。

## 身体と学習

Minecraftで生活している間は、仮想の部屋・身体・配置物の活動を止め、元の状態を保存する。水分・温度・音の不快・仮想の疲労を使わず、満腹度と体力から身体を維持する必要を計算する。好奇心・社会的な欲求・自己尊重・性格・会話は継続する。切断中も仮想の身体へ自動で切り替えない。

初期の追加知識はブロック・生物・移動・採掘・拾得・食事・危険の基本と操作方法だけ。完成した攻略ルート、地下の鉱石位置、ワールドのシードや他人のインベントリは渡さない。画面を読んだりマウスを動かしたりしてMinecraftを操作する方式ではない。

ESIはMODが観察した周囲と自分の所持品から次の操作を選ぶ。目標・性格・欲求・最近の実際の行動結果・関連する教わった知識を判断に渡す。質問には通常の会話で答えられる。成功の宣言だけでは成功として記録せず、MODが返した実際の結果を保存する。採掘によるブロック変化とアイテム取得を区別し、食事は食べ物の消費とゲージの回復を確認する。

この版の成長は、経験・教え・訂正を保存して次の判断に使うこと。基礎言語モデルの重みを自動で訓練したり、事前学習済みの知識を消したりする仕組みではない。

## この版の範囲

対応するのは、周囲の観察、短い移動とジャンプ、見える足場への歩行、手に持つ物の変更、採掘、拾得、食事、単純な使用・ブロック設置・近くの生物への攻撃。ほかのプレイヤーへの攻撃は実行しない。設置は、所持して手に持ったブロックを、見えて届くブロックの面に通常の使用操作で置く。

経路は近くに見える足場だけを使う。長距離の経路計画、作業台でのクラフト、チェスト内の操作、複雑な建築、攻略全体の自動達成は追加していない。死亡時はCarpetの仮想プレイヤーの仕様で退出するため、自律活動を続けるには状態を確認して再接続する。

ESIの人格・行動記録は既存のセーブDB、プレイヤーの位置・所持品・体力はMinecraftのワールドへ保存する。同じESIを戻すには、同じセーブと同じワールドを使う。
