# Minecraftで生活する — ESI-04 0.4.6 / Fabric 1.21.11

> 現行0.4.8ではMinecraftプラグインを一時無効化し、会話機能の改善へ移行しています。このページは0.4.6の記録です。ワールド・経験は保持します。更新と利用方法は [会話の改善](ESI-04-会話の改善.md) を参照してください。

ESIの人格・会話・記憶を引き継ぎ、Minecraftのワールドに独立したプレイヤーとして参加させる。現在のプラグインは、MinecraftとESIを**同じPC**で実行する構成に対応する。シングルプレイではMODを導入したFabricでワールドを開く。専用サーバーでは、そのサーバーとESIを同じPCで実行し、サーバー側にもMODを導入する。

0.4.6は、Minecraftでの生活の目的と会話を同じ状態へつなぐ更新。具体的な行動指示がなくても、自分の欲求・関心・体験から目的を選び、試し、結果を確かめる。目的は会話や中断の後も保持し、保留・再開・見直し・取りやめを判断する。前版から直接更新できる。**ESI本体とESI Bridge MODを両方更新**し、旧Bridge JARと新Bridge JARを同時に入れない。

## 最初の導入

1. ESIを0.4.6へ更新する。既存の `data`・`models`・Python環境・AivisSpeechは残す。
2. Minecraft Java版 **1.21.11** をFabric Loaderで起動できるようにする。1.21.1とは別の版。動作確認時のLoaderは0.19.5、Javaは21。
3. Minecraftの、その起動構成の `mods` フォルダーへ、次の3つを入れる。別バージョンの同じMODを重複して入れない。

| ファイル | 入手先 |
| --- | --- |
| `esi-minecraft-bridge-0.4.6.jar` | このZIPの `plugins/minecraft/release` フォルダー |
| Fabric API **0.141.6+1.21.11** | [Fabric APIの配布ページ](https://modrinth.com/mod/fabric-api/versions?g=1.21.11) |
| Carpet **1.4.194 / Minecraft 1.21.11** | [Carpetの配布ページ](https://modrinth.com/mod/carpet/version/HzPcczDK) |

JARは展開しない。ESI BridgeはCarpetの仮想プレイヤー機能を使う。Minecraft本体・Fabric・依存MODはESIのPython環境とは別に導入する。依存ファイルの正確なURL・ハッシュは `plugins/minecraft/dependencies.json` に記録している。

WindowsではZIPの **`Minecraft連携MODを準備.cmd`** を開くと、依存MODを取得し、SHA-256を確認して、`plugins/minecraft/release/mods` に必要な3つのJARをそろえる。そのフォルダーが開いたら、中の3つをMinecraft側の `mods` へコピーすればよい。Fabric Loader自体の導入は先に行う。

## ワールドへ接続する

1. Fabricでワールドに入り、チャットへ **`/esi link`** と入力する。シングルプレイでもこの接続コマンドを使える。
2. 自分に表示された接続先URLと接続コードを確認する。コードのメッセージはクリックでコピーできる。接続先は通常 `http://127.0.0.1:8766`。そのポートが使用中なら8767〜8775を使うので、表示されたURLを指定する。
3. ESI本体を開始し、「プラグイン・Minecraft」タブを開く。Minecraftを選び、接続先とコードを貼り付け、「ワールドに接続してESIを参加させる」を押す。
4. Minecraftを一時停止している場合は再開する。ESIが `ESI_…` という別プレイヤーとして参加する。初参加は利用者の近く、次回からはそのESIが前回いた場所に戻る。
5. 満腹度・体力・所持品・見えている周囲が表示されたら接続完了。
6. **希望欄は空欄のまま「自律生活を開始・再開」を押す。** 自分の関心と必要から生活の目的を考える。希望や相談がある場合だけ欄へ入力し、「希望と設定を適用」を押す。「選んだ操作を1回試す」は個別の動作確認用。

開始直後の自律活動はOFF。再起動しても接続や行動を勝手に再開しない。「このPCに接続先・コードを保存する」は任意で、セーブDBと診断にはコードを入れない。`/esi link` をやり直すとコードが変わる。

## 指示せずに生活を観察する

1. 安定して立てる場所で接続し、希望欄を空欄にして自律生活を開始する。何をすべきかという操作指示は入力しなくてよい。
2. 「生活の目的・会話」で、自分で選んだ目的、重視した欲求、選択理由の要約、保留した目的を見る。「現在の観察・操作」で実際の変化を確認する。
3. 普通に「今は何が気になっている？」「ここでは何をして過ごしたい？」などと話しかける。目的・周囲・実際の経験に関係する内容で答え、返答後に生活の判断へ戻る。
4. 何かを渡したい場合は近くにアイテムを投げる。拾得・採掘・食事の結果は通常のゲーム処理から確認する。渡すことと、次の操作を指定することは別。
5. 「そろそろ暗くなってきたね」のような提案や状況の話も、その後の判断で考慮する。命令形だけを拾う方式ではない。

目的を作ること、待つこと、尋ねること、別の目的へ移ることもESIの判断。常時動いていることだけを自律生活の指標にはしない。「生活の目的・会話」と状態表示で、考え中・操作中・会話中・選んだ待機・停止・切断を区別できる。小型モデルは誤った予想や不適切な操作を選ぶ場合がある。その結果と訂正を残し、次の判断へ渡す。

## 会話する

ESI本体のマイク・文字入力と、ゲーム内の呼びかけは、同じ会話履歴・人格・生活状態を使う。ゲーム内では接続した本人から次のどちらかで話しかける。

- `/esi say 今は何を考えているの？`
- 通常のチャットに `@ESI 今は何を考えているの？`

返答は呼びかけた接続者のチャットへ表示し、本体の会話・音声にも反映する。他のプレイヤーの雑談やESI自身の表示を自動で学習入力にはしない。本体での通常会話はゲーム内へ一括転送しない。ESIがMinecraftについて質問を選んだ場合は、ゲーム内にも表示する。

質問に答えるための専用ボタンは不要。普段の音声・文字入力・ゲーム内の呼びかけで答えられる。返答がないことを理由に生活全体を止め続けず、他に自分でできることを検討する。会話中は新しい生活判断を待ち、終わったら目的を保持して考え直す。実行中の短い操作は完了する場合がある。即座に止めたい場合は「操作を止めて」または停止ボタンを使う。

「手に何を持っている？」「今、何が見える？」「体調はどう？」は現在の観察から答える。切断中は過去の観察を現在の状態として答えない。行動指示を伝えても、OFFの自律生活を勝手にONにはしない。
最初から所持品や満腹度を補充するESI用の処理は入れていない。採掘・食事・拾得・道具の耐久度はMinecraftの通常の仕組みを使う。難易度やゲームルールによる回復・死亡・ドロップは、そのワールドの設定に従う。

## 停止と切り替え

| 操作 | 結果 |
| --- | --- |
| ESIの「行動を停止」／「操作を止めて」と話す | 現在の操作と自律活動を止める。プレイヤーは残る |
| ワールド内の `/esi stop` | Minecraft側で以後の操作も停止する。再開時はESIで再接続する |
| ESIの「切断」／ワールド内の `/esi disconnect` | ESIプレイヤーを退出させる |
| 利用者がワールドから退出 | ESIも退出する |
| ESIとの通信が約30秒途切れる | 操作を止め、ESIを退出させる |
| ESIの「仮想の部屋へ戻る」 | Minecraft接続を終了し、保存していた仮想の部屋・身体へ戻る |

Minecraft側で停止・退出した後、再接続するまでは自律活動を開始できない。ESCメニューなどでワールドが停止すると接続処理も進まない。再開してから接続する。接続できない時は同じワールドで `/esi link` をやり直し、表示されたURLと新しいコードを使う。

停止・切断時は開いた収納や作業画面も閉じる。変化のない操作が続いた場合は、自律生活をOFFにせず、目的や方法を見直す。同じ場所・手持ち・対象で繰り返し変化がなかった操作は、次の候補から一時的に外す。別の操作、持ち替え、別の目的、質問、待機を自分で選ぶ。所持品や身体の重要な変化が推論中にあった場合は、古い判断を取り消して考え直す。

## 小さな目標と経験を見る

「プラグイン・Minecraft」の中に次の表示がある。

| 表示 | 確認できること |
| --- | --- |
| 生活の目的・会話 | 現在・保留・確認済み・取りやめの目的、選んだ理由の要約、確認条件、最近の会話 |
| 現在の観察・操作 | 手に持っている物と所持品の区別、実際に見える周囲、解放済みレシピ、開いている収納 |
| 小さな目標・経験 | 今回確かめたいこと、確認する変化、重視した欲求、次に考えたいこと、前後の変化と出典 |
| 見た場所の記憶 | 訪問した場所と視認だけの場所、その時に見た物・危険候補・過去に開いた収納の中身・最終確認時刻 |

ESIは目標を小さく考え、毎回の操作前に観察し直す。例えば「石を拾う」が目的なら、ブロックが壊れただけでは達成としない。持ち替え・採掘・拾得のどの変化を確認したかを残す。未確認や失敗なら、その結果を次の判断へ渡して見直す。続きに書かれた計画は未実行の意図であり、実行結果とは別。

希望や新しい会話があれば、現在の目的と比べて見直す。自分で選んだ目的も保留して戻れる。過去の経験は残すが、古い操作の結果で新しい目的を達成済みにしない。意図と実際の確認条件は「小さな目標・経験」で見比べられる。

ESIは、現在の手持ちと「今回使いたい物」を別々に指定する。使いたい物が所持品の別スロットにあれば、まず持ち替えだけを実行して確認する。採掘などの次の操作は、持ち替え後に改めて選ぶ。使う道具や対象はESI自身が選ぶので、適さない物で試すことも経験として残る。

場所はワールドとディメンションを分け、4ブロック単位の粗いセルに実際に見た範囲だけを記録する。過去の場所に今も同じ物があるとは限らない。移動時は現在見える足場を確認し、遠くの記憶した場所へ瞬間移動しない。隠れた鉱石・未開封の収納の中身・シードは記録しない。

自分で初めて訪れた範囲は場所の学習になり、実際の取得・食事などとともに欲求や活動の好みへ反映する。同じ場所を回ることや見回しだけで学習したことにはしない。空腹などが強まったら、続けていた関心と比較し、別の目的へ移ることも選べる。以前の目的は保留して残る。

「手に何を持っている？」「さっきの結果は？」「何を覚えた？」などで確認できる。教わった説明、観察された変化、行動の理由や原因の推測は区別する。誤った教えを先回りして正解へ置き換えることはせず、訂正や違う経験も残して次の判断に使う。

## クラフトと収納を試す

1. ESIへ丸太などの材料を渡す。レシピは、そのESIプレイヤーがMinecraft内で解放したレシピブックの範囲だけを利用する。レシピ一覧で「今作れる」かを確認する。全レシピや攻略手順を一括で教える処理はない。
2. 「所持品の丸太で板材を作って」と目標を伝える。手持ちの2×2で作れる物はそのまま、3×3が必要なら見える作業台へ近づいて「使う・開く」を行う。完成品だけでなく材料の減少も確認する。
3. チェスト・樽などを近くに置き、ESIが実際に見て近づけるようにする。「チェストを開いて、持っている板材を預けて」と目標を伝える。収納は開いた後に中身が観察に出る。
4. 「収納の板材を取り出して」と頼む。預ける・取り出すはスタック単位で、容量や通常のスロット制限に従う。閉じた収納、別の収納へ切り替わった古い観察のままでは移動しない。

小型モデルが迷った時は、手動の一覧から「使う・開く」「クラフトする」「収納へ預ける」「収納から取り出す」を一つずつ試せる。これも前後の観察を記録する。レシピ未解放・材料不足・作業場所の不足・所持品の空き不足は成功として扱わない。作業台以外の製錬や醸造の自動操作は今回の対象外。

## 身体と学習

Minecraftで生活している間は、仮想の部屋・身体・配置物の活動を止め、元の状態を保存する。水分・温度・音の不快・仮想の疲労を使わず、満腹度と体力から身体を維持する必要を計算する。好奇心・社会的な欲求・自己尊重・性格・会話は継続する。切断中も仮想の身体へ自動で切り替えない。

初期の追加知識はブロック・生物・移動・採掘・拾得・食事・危険の基本と操作方法だけ。完成した攻略ルート、地下の鉱石位置、ワールドのシードや他人のインベントリは渡さない。画面を読んだりマウスを動かしたりしてMinecraftを操作する方式ではない。

ESIはMODが観察した周囲と自分の所持品から次の操作を選ぶ。目標・性格・欲求・最近の実際の行動結果・関連する教わった知識を判断に渡す。質問には通常の会話で答えられる。成功の宣言だけでは成功として記録せず、MODが返した実際の結果を保存する。採掘によるブロック変化とアイテム取得を区別し、食事は食べ物の消費とゲージの回復を確認する。

この版の成長は、経験・教え・訂正を保存して次の判断に使うこと。基礎言語モデルの重みを自動で訓練したり、事前学習済みの知識を消したりする仕組みではない。

## この版の範囲

対応するのは、周囲の観察、短い移動とジャンプ、見える足場への歩行、手に持つ物の変更、採掘、拾得、食事、単純な使用・ブロック設置・近くの生物への攻撃。ほかのプレイヤーへの攻撃は実行しない。設置は、所持して手に持ったブロックを、見えて届くブロックの面に通常の使用操作で置く。

経路は近くに見える足場だけを使う。作業台を含む通常クラフトと、開いたチェスト・樽・ホッパー・シュルカーボックスの収納操作に対応する。自律生活の判断・継続と、複雑な建築・製錬・醸造・攻略全体の自動達成は別の能力。後者の専用操作は今回追加していない。小型モデルが必ず正しい手順を選べることを保証するものではない。死亡時はCarpetの仮想プレイヤーの仕様で退出するため、自律活動を続けるには状態を確認して再接続する。

ESIの人格・行動記録は既存のセーブDB、プレイヤーの位置・所持品・体力はMinecraftのワールドへ保存する。同じESIを戻すには、同じセーブと同じワールドを使う。
