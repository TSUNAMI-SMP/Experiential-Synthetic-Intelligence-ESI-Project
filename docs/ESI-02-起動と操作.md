# ESI-02の起動と操作（開発用の手順）

**現在は開発中です。完成した配布版の導入手順ではありません。** 凛音エルの完成Live2Dモデル、WindowsのGPU・マイク・スピーカーを使った最終確認が残っています。1〜6を完了するまで正式なZIP・リリースを公開しません。

## 最初の1回

1. ESI-02のファイルが入っているフォルダーを開きます。このフォルダーのことを、技術的な説明では「プロジェクトのルート」と呼びます。
2. **「ESI-02を起動.cmd」** をダブルクリックします。文字のコマンドを自分で打つ必要はありません。
3. 初回は画面・聞き取り・音声に必要なものを準備します。文字が流れる窓は、準備が終わるまで開いたままにします。Python 3.12の64ビット版がない場合は、案内に従って公式ページから導入し、もう一度同じファイルを開きます。
4. 起動画面で「AIデータの準備」が案内されたら押します。初回は数GBをダウンロードします。すでにある違うデータを勝手に上書きしません。
5. AivisSpeech本体を導入していない場合は「AivisSpeechの公式配布」から導入します。「AivisSpeechを選ぶ」で `AivisSpeech.exe` を選べます。バージョン番号だけで1.2.0を要求することはなく、実際の接続と凛音エルを確認します。
6. 準備と接続ができるとESIの本体画面が開きます。GPUを使えなかった場合は、CPUを使う理由や未確認の状態を表示します。

GPUの聞き取りには追加のライブラリを導入します。導入ができなかった場合、既定のauto設定ではCPUへ切り替えます。GPUでの計算を確認する前に「GPUで動いている」と表示しません。ドライバーのインストールはこの処理では行いません。

## 毎回の起動と会話

1. 「ESI-02を起動.cmd」をダブルクリックします。前回本体で開いたセーブを記憶します。
2. 「入力マイク」と「出力スピーカー」を確認します。「音のテスト」で短い音が聞こえるか確認し、終わったら「開始」を押します。機器の変更と音のテストは停止中に行います。
3. マイクをONにして、短く話しかけます。文字でも入力できます。アイコンと説明で、聞き取り・文章を考える・声を作る・発声を区別します。
4. 終わるときは「停止」、または本体画面を閉じます。終了時に保存します。「保存」は途中で保存したい場合に使います。

音声ファイルの生成と、スピーカーから実際に鳴ったことは別々に確認します。再生がOFF・中断・未確認の場合は、画面にその状態を表示します。

## セーブを開く

本体の「セーブを開く」、または起動画面の「セーブを選ぶ」で選びます。ESI-01のセーブを選んだ場合は、新しいESI-02の保存先を聞き、元のセーブを残してコピーします。違うソフトのファイルや壊れたセーブを選んだときは、現在のセーブをそのまま保持します。

前回のセーブが見つからない場合は、新しいものへ勝手に置き換えません。起動画面から保存先を選び直します。

## 本体を最小化して使う

- 「丸型マイクボタンを表示」で、独立した丸いボタンを右中央に出します。クリックでマイクを切り替えます。ESIが停止中ならマイクを使って開始します。右クリックで開始・停止・本体の表示を選べます。ドラッグで位置を変えられます。
- 「立ち絵を表示」で、別の窓に凛音エルを出します。立ち絵をドラッグして移動し、小さい−／＋で大きさを変えます。×は表示だけを隠し、ESIの動作は続けます。
- 本体を最小化しても、両方の窓は残ります。表示・位置・大きさを保存します。画面外へ動かしても自動で戻しません。戻したい場合だけ本体の「位置を戻す」を押します。

現在の立ち絵は静止画の下書きです。この手順のデスクトップ操作を、Live2Dのモデル制作が完了したものとして扱わないでください。

## 経験を重ねる

まずは普通に会話してください。例として「私の名前は太郎です」「私は紅茶が好きです」と短く伝え、あとで「私の名前を覚えていますか」と聞けます。「記憶を見る・直す」で、元の発言と、覚えた内容を確認・訂正・削除できます。自動整理には間違いもあるため、必要に応じて直します。

「仮想の部屋・身体」では、休息・移動・水分・温度などの経験を積みます。「欲求・行動の学習」では、実際に観測できた結果から、行動後の見通しを更新します。お願いに対応する・あとで・断るは自由です。文章の生成や発声だけを成功の報酬にしません。

ここで増えるのは対話の記憶と行動の経験です。会話用の言語モデルそのものを再訓練する機能とは別です。身体や脳内物質に相当する値は仮想空間の計算値です。
