# ESI-03 の導入と確認

ESI-03（0.3.0）の実装とクラウドでの動作検証を終えた版の手順です。WindowsのGPU・物理マイク・スピーカーでの結果は、下記の項目で確認します。

## ESI-02 から更新する

1. ESI-02 の画面を閉じる。
2. [GitHub の ESI-03 ZIP](https://github.com/TSUNAMI-SMP/Experiential-Synthetic-Intelligence-ESI-Project/archive/refs/heads/esi-03-development.zip) をダウンロードして展開する。
3. 展開した内容を、今までの ESI-02 フォルダーへコピーして更新する。`data`、`models`、`.venv-esi02`、AivisSpeech のファイルは残す。Git の管理情報がない ZIP 版では `git pull` を使わない。
4. `ESI-03を起動.cmd` をダブルクリックする。ESI-02 の Python 環境とダウンロード済みモデルを利用できる。
5. 最初の起動で前回の ESI-02 のセーブを新しい ESI-03 用ファイルへコピーする。元セーブと、一貫した元データのアーカイブを保持する。

移行先は通常 `data\esi03\session.sqlite3`、元データのアーカイブは `session.esi02-original.sqlite3`。ESI-02 のセーブを上書きしない。別の保存場所なら、起動画面の「セーブを選ぶ」で選択してコピー先を指定できる。

初めて導入する場合は Python 3.12 の64ビット版と AivisSpeech を導入し、`ESI-03の初回準備・更新.cmd`、`ESI-03を起動.cmd` の順に実行する。AIデータがなければ起動画面の「AIデータの準備」を使う。既存の指定版データは再ダウンロードせず照合する。

## 性格・欲求・関心

本体の「性格・欲求・成長・探索」で設定する。

- **性格**: 自己尊重・誠実さ・成長・相互尊重・自立が人格の軸。経験だけでは変更されない。好奇心、社交性、信頼、慎重さ、固執、粘り強さ、柔軟さ、承認・愛着への反応、遊び心は経験から少しずつ変わる。
- **欲求・習慣**: 14種類の欲求と活動ごとの期待・好み・慣れ・満足を表示する。同じ資料の反復で報酬を増やさず、活動への慣れと時間による回復を持つ。
- **関心・成長目標**: 気になったこと、理由、保留・調査の状態を確認する。話題を追加し、疑問を保留し、選んだ疑問を調べられる。
- **信念・出典・訂正**: 以前の教え、新しい説明、確信度、食い違い、変更履歴を確認する。世界の正解へ勝手に置き換えない。固執の強さなどによって再考の速さが変わる。
- **成長の履歴**: 何を知りたかったか、何を調べたか、経験から何を更新したかを確認する。

自発的な質問と公開Webの調査は初期状態でON。質問の最短間隔は150秒、探索とPC操作は一日に12回が初期設定。疲れているときや、本人が断った・保留したときは質問を控える。「話しかけないで」で自発的な質問をOFFにする。設定画面で再開できる。

起動画面では別のキャラクターを作成できる。それぞれのセーブ、記憶、信念、欲求、習慣、経験は独立し、言語・音声ソフトを共用する。

## Web・フォルダー・PC操作

「探索・PC操作」で検索先、調べるホスト名、読めるフォルダー、学習ノートの保存先を設定する。

Webの初期範囲はWikipedia・検索先の公開ホスト。検索結果の抜粋と元記事を取得できた資料を区別し、出典・取得時刻・ハッシュと未確認であることを記録する。資料と以前の教えの食い違いは再考の対象にする。検索制限や関連資料が見つからない場合は未取得として記録する。

ファイル調査は選択したフォルダー内のテキスト資料。リンクやジャンクション経由で範囲外へ進まない。ブラウザーでURLを開く、資料を別のアプリで開く、新しい学習ノートを保存する操作は、設定した機能と範囲内で実行する。Webや文書の本文をコマンドとして実行しない。

「調査・操作を停止」で進行中の操作を中止できる。設定変更後の遅い結果や、再起動前に実行中だった操作を自動で学習・再実行しない。

## GPU 設定・計測

会話を止め、「GPU設定・計測」で実行先、文脈トークン数、FlashAttention、KVキャッシュ、聞き取りの計算形式を調整する。

標準は4096トークン・FlashAttention AUTO・Q8 KVキャッシュ。F16も選べる。量子化KVではFlashAttentionをAUTOまたはONにする。RTX 5060 の8GBでは、モデル以外に聞き取りや描画の余裕を残して設定する。

会話の計測では固定サンプルを3回計算し、最初の応答と全体の時間を記録する。聞き取りは30秒以内の音声ファイルで計測できる。計測の出力はキャラクターの学習に使わない。聞き取りは実際に成功した計算形式を表示する。

Qwenの重みはQ4_K_Mで、NVFP4には変換しない。GPUに対応していることと、Blackwell向けの最大性能を確認したことは別。クラウドのCPU計測をRTX 5060の速度として扱わない。

## 確認する項目

- 起動、言語と聞き取りの実行先、マイク音量、スピーカー出力、発話中断、声と口の同期。
- 教えていない地名には分からないと伝える。誤った教えと訂正を記録し、再起動後も内容と出典を保持する。
- 性格の違いが話し方と、信念の更新・質問・行動選択に現れる。
- 指定した資料から出典付きの知識を保存する。停止・保留・範囲変更が反映される。
- 通常の目・閉眼・再び開眼、顔・後ろ髪・首・襟の重なり、髪の輪郭。

「診断を保存」または `ESI-03の診断を保存.cmd` でGPU・音声・接続・保存形式の診断を出せる。診断には会話、録音、信念、取得した資料の本文を含めない。

会話だけで基礎言語モデルの重みが更新される版ではない。成長は、経験の保存・信念の再考・性格と活動の好み・関心と行動選択の変化として実装している。
