# ESI-03 実装・検証記録

状態: ESI-03（0.3.0）の実装・クラウド検証完了。ESI-02 の実機確認済み版から独立したブランチで配布。ESI-03のWindows・RTX 5060・物理音声の確認は利用者の実機で行う。

## 今回の到達目標

ESI-02 の音声、GPU、仮想身体、セーブ、元絵を保ち、経験から信念・関心・行動が変化する ESI-03 を実装する。基礎言語モデルの重みのオンライン更新や、生物学的な意識・快楽の成立を完成条件とはしない。

1. 教わった内容と観測を根拠に自然に話す。未知の地域・雑学を事前学習から取り出さない。聞き取りの不確実性を確認し、固定の勧誘で締めない。
2. 信念に出典・確信度・代替説・訂正履歴を持つ。誤った教えを覚え、後の訂正も覚える。性格により再考の速さを変える。
3. 自己尊重、誠実さ、成長、相互尊重を人格の軸にする。好奇心・社交性・信頼・慎重さ・固執などはキャラクターごとに設定し、経験から緩やかに変える。人格の軸を無断で上書きしない。
4. 身体維持・快適さ・休息に加え、好奇心・新奇性・成長・有能感・自律性・意味・社会的つながり・所属・承認・愛着・楽しみの欲求を持つ。経験から活動の好み、慣れ、飽き、回復を学ぶ。
5. 未解決の疑問・興味・成長目標を保存する。現在の身体と欲求を考慮して自分から質問する。断りや停止を尊重し、同じ質問を繰り返さない。
6. 疑問→Web検索／指定フォルダーの調査→引用付き記録→信念の再考を実行する。許可した機能と範囲内でファイル・ブラウザーを操作する。Webや文書の本文を操作命令にしない。
7. 仮想身体・環境の実測差、明示的な相手の返答、実際に得た資料を学習結果に使う。自分の生成文を証拠や報酬にしない。
8. キャラクター、欲求、信念、関心、活動の理由、成長履歴、探索範囲を画面で確認・設定できる。
9. 実際の推論時間とGPU状態を計測し、FlashAttention、KVキャッシュ、ASRの計算形式を設定する。Blackwellの性能活用は測定結果と形式の対応範囲で説明する。
10. 髪の輪郭線を原画から保ち、カクつくメッシュを修正する。保存したCubismソースからの再出力、開閉眼、顔・髪・襟の重なりを再検証する。

## 保存と再開

- ESI-02 は読み取り専用バックアップから新しい名前へコピー移行する。元の保存データには書かない。
- キャラクターごとに独立した保存データ。言語・音声モデルは共用し、複数モデルをGPUへ同時ロードしない。
- 個々の状態変更を永続化する。クラッシュ後に発声や外部操作を自動再実行しない。
- 長い実装ではローカルのコミットと引継ぎ記録を残す。未完成の成果物を公開しない。

## 検証の判定条件

- 教えていない固有知識を回答しない／誤った教えを再現／訂正・衝突・保留とその履歴を確認。
- キャラクターの性格差が信念の更新と行動選択の両方に現れ、口調だけの差になっていない。
- 自発的な疑問が具体的な関心・身体状態・目標を根拠に選ばれ、断り・停止・疲労時の休息に従う。
- 報酬の重複適用、自分の発声からの学習、無限の同じ探索、無断の人格変更が起きない。
- Web検索と資料閲覧が実際に動き、引用元・取得時刻・未確認であることを残す。指定範囲外のファイルと操作を拒否。
- セーブ移行・クラッシュ復旧・複数キャラ切替で状態を失わず、ESI-02の元セーブを保持。
- UI・音声・実サービス・ネイティブ描画の検証。クラウドで確認できないWindows/GPU/音声の実機項目は明示し、未検証の性能を断言しない。
