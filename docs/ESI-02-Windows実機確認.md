# ESI-02 Windows実機確認（開発中）

クラウドで開発を続け、PCで確認した結果を同じチャットへ返すための手順です。完成版の導入案内ではありません。凛音エルのCubismモデルは同梱・クラウド検証済みで、Windows/GPU/実音声機器の確認が残っています。

## 確認用のコードを配置する

最新版はGitHubの [esi-02-development ブランチ](https://github.com/TSUNAMI-SMP/Experiential-Synthetic-Intelligence-ESI-Project/tree/esi-02-development)です。`main` はESI-01のまま維持しています。完成版のZIP・リリースはまだ生成していません。

Git for Windowsが使える場合、確認用フォルダーを置きたい場所でPowerShellを開き、次を実行します。既存のESI-01を上書きせず、新しい `ESI-02-check` を作ります。

```powershell
git clone --branch esi-02-development --single-branch https://github.com/TSUNAMI-SMP/Experiential-Synthetic-Intelligence-ESI-Project.git .\ESI-02-check
```

Gitがない場合は先にGit for Windowsの導入が必要です。対話や開発の説明はこのクラウドチャットに残したまま進めます。開発履歴は検証済みの `ESI-02-recovery-latest.bundle` にも保存しています。

すでにESI-01用の `models` フォルダーを持っている場合は、確認用フォルダーにもコピーして再利用できます。AIデータの指定版が違う場合は、準備画面が知らせます。使用中のESI-01と、以前手動で起動した言語ソフトは閉じてから確認を始めます。AivisSpeechは開いておき、凛音エルを登録します。

## 1. 起動と接続を確認する

1. **「ESI-02の初回準備・更新.cmd」** を一度実行します。Python 3.12の64ビット版が必要です。導入記録は `data/esi02/logs/install-…log` に保存されます。
2. **「ESI-02を起動.cmd」** をダブルクリックします。必要なら「AIデータの準備」を実行します。
3. 本体が開いたら「診断を保存」を押します。開かない場合は起動画面の同じボタン、または **「ESI-02の診断を保存.cmd」** を使います。

確認したい結果は、Qwen3-4Bへの接続と、AivisSpeechに登録した凛音エルの一致です。診断が接続成功でも、まだ会話・再生の実機確認は終わっていません。

## 2. マイクとスピーカーを確認する

1. 停止中に、使う入力マイクと出力スピーカーを選びます。
2. 「音のテスト」を押し、選んだ機器から短い音が聞こえるか確かめます。
3. 「開始」を押してマイクをONにし、「こんにちは」と一度話します。入力音量が動くか、聞き取った文章が表示されるかを確認します。
4. 返答を待ち、凛音エルの声が聞こえるか確認します。発声中に別の短い質問をして、古い返答が中断されるかも確認します。
5. この状態でもう一度「診断を保存」を押します。実際の聞き取りで使用した処理機器が記録されます。

「GPUが見つかった」「GPU用ライブラリが入った」と、GPUで実際に計算できたことは別々に記録します。CPUへの切替理由や使用機器が未確認の表示が出たら、そのまま報告してください。

## 3. 保存・切替・独立窓を確認する

- 「丸型マイクボタンを表示」「立ち絵を表示」をONにし、本体を最小化して開始・停止・マイク切替を試します。位置・サイズを変えて再起動し、表示設定が残るか確認します。
- 「保存」を押して終了し、同じセーブを開いて会話・記憶が残るか確認します。
- 別のセーブを開く際、準備中も画面が動くか、中止して元のセーブを保持するか確認します。ESI-01のセーブは新しい名前へコピーして移行します。
- 同梱の凛音エルで瞬き、口、呼吸、髪と輪の小さい揺れ、背景透過、モデル再読込み、終了を確認します。既存の設定が静止画なら「凛音エル」を押します。返答の声で口が開き、発声を中断すると閉じるかも確認してください。

## 結果をこのチャットへ返す

まず、最後に保存した `data/esi02/diagnostics/diagnostic-…json` を添付し、次の結果を短く添えてください。

- 音のテストが聞こえたか。
- 話したときに入力音量が動き、文章が表示されたか。
- 凛音エルの返答が聞こえたか。
- 発声中に質問すると古い返答が止まったか。
- 保存・再起動、セーブ切替、最小化中の操作で困った点があったか。
- 凛音エルの表示、瞬き、声と口の同期、髪・輪の動き、モデル再読込みで困った点があったか。

画面が開かずJSONも作れない場合は、表示されたエラーと最新の起動・導入ログを使って問題の位置を確認します。
