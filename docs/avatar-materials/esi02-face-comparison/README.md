# 目・眉・首の修正比較

同じカメラ、同じ大きさ、停止した姿勢で、ESI-02が使うネイティブ描画から直接保存した画像です。画像の描き直しや合成はしていません。

| ![修正前の閉眼](before-closed.png) | ![修正後の閉眼](closed.png) |

再開眼: ![まばたき後の再開眼](reopened.png)

首の上部を含む胴が顔の手前に描画されていたため、顔を胴より前へ置き、襟の前面を独立させて顔・首より前へ置きました。頭の位置も調整し、顎と襟の間に首が見えるようにしています。

通常の目は幅と高さを117%に調整しました。左右を反転した同じ形にし、目に含まれていた眉はメッシュの表示範囲から除外しています。新しい眉は原画を参照して作成した独立素材です。太さ・位置・不透明度を調整し、片側を反転して左右をそろえ、髪より前に描画します。元の原画と画素単位で同一の部品ではありません。

閉眼も眉を除外し、横幅・高さ・位置を調整しました。実際に見えるまつげの幅は左右とも62pxで、同じ比較画像の開眼（左68px、右77px）を超えません。これは画像差分内の暗い連結領域による測定で、眼球の寸法ではありません。開眼の表示には髪の重なりも含まれます。閉眼の左右の形・高さ・反転軸は、画像とは別に実メッシュでも確認しています。

開眼→閉眼→再開眼を描画し、再開眼が開眼と画素単位で一致すること、まばたきで目・眉・他の部品の頂点が移動しないことを確認しました。結果は [comparison.json](comparison.json)。開閉の途中は2枚の絵を切り替える方式を維持しています。

確認コマンド（描画可能な環境で実行）:

```sh
python scripts/validate-rinne-face.py --output /tmp/esi02-face-check
python scripts/validate-rinne-model.py --output /tmp/esi02-pose-check
```

保存したCMO3を開き直し、MOC3・model3・physics3・cdi3・テクスチャの5ファイルが再書き出しでも同一になることを確認しています。原画の参照先は [rion-el.png](../../../src/esi/resources/rion-el.png)。利用者のWindows画面での最終的な見え方は、更新後に確認してください。
