# 凛音エルのアバター素材と制作の引き継ぎ

ユーザーが提示した立ち絵を基に、画像編集機能で表示用透過PNGと部品表の下書きを作成しました。隠れた部分を生成で補っているため、元絵と完全一致する分離データではありません。元絵と顔・目・口の追加下書きを格納した [制作途中のレイヤー付きPSDとCMO3](esi02-source-work/README.md) を保存しました。CMO3は実際のCubism Editorで作成しています。部品の位置合わせと清書を終えたPSD、完成したリギング、実行用MOC3は未制作です。

- 表示用画像: `src/esi/resources/rion-el.png`。1024×1536、透過PNG。
- 部品表の下書き: `rion-el-parts-draft.png`。透明背景の1枚の画像に、部品を並べています。各部品の縁、顔と髪の重なり、ジャケットの袖と肩、股関節、輪郭の塗りを清書する必要があります。

部品表は上から4行、左から4列です。1行目は輪・後ろ髪と頭帯・前髪・顔と首。2行目は左右の目・眉・口。3行目は上着の胴・左右の袖と手・短パン。4行目は左右の脚・左右のブーツです。目の白目／虹彩／まぶた、上下の唇、袖／手、髪の房は、さらに独立したレイヤーに分けてください。左右の呼び方は作画上の左右を確定して命名します。

## 清書するレイヤーの目安

| グループ | 分ける部品 |
| --- | --- |
| 輪 | 輪本体、光。独立した回転・上下移動 |
| 髪 | 後ろ髪、左横髪、右横髪、前髪の房、頭帯 |
| 顔 | 顔の土台、左右の耳、首、必要なら影 |
| 左右の目 | 白目、虹彩、瞳、上まぶたとまつ毛、下まぶた、ハイライト |
| 眉 | 左眉、右眉 |
| 口 | 上唇、下唇、口内、舌、必要な歯 |
| 上半身 | 上着の胴、襟、前開き、左右の肩・袖、裾、必要な前面装飾 |
| 腕 | 左右の袖、手首、手。回転で見える付け根も塗る |
| 下半身 | 短パン、左右の脚・ブーツ。股関節とひざ付近も塗り足す |

すべてのレイヤーを同じキャンバス座標に組み立ててPSDにします。Cubismでは部品をArtMeshにし、頭・身体・髪・腕を親子の変形器に分け、横や上下を向いた際の隙間と重なりを確認します。まだ空のモデルを書き出したり、PNGをMOC3と呼んだりしないでください。

## ESIの表示機能が使うパラメータ

| パラメータ | 推奨する制作 |
| --- | --- |
| `ParamAngleX/Y/Z` | 左右、上下、傾き。顔・耳・髪・輪の追従 |
| `ParamEyeLOpen` / `ParamEyeROpen` | 0〜1の瞬き |
| `ParamEyeBallX/Y` | 視線の左右・上下 |
| `ParamBreath` | 身体・襟の穏やかな呼吸 |
| `ParamMouthOpenY` | 0〜1の口の開閉。ESI-02では実際の出力音声の音量・再生予定時刻で動かす |
| `ParamMouthForm` | 口形状の補助。現在のESIでは表情を自動推定して変更しない |

髪・輪の揺れは物理演算の設定を `.physics3.json` として書き出します。待機モーションや表情はモデルに含められますが、現在のESIは「喜び」などを推定して任意の表情を選ぶ機能を実装していません。

## 制作物の受け渡しと確認

制作途中のPSDとCMO3は実行用モデルとは別に保持してください。Cubism Editorから、MOC3、model3.json、テクスチャ、physics3.json、必要なモーション・表情を同じフォルダーへ書き出します。JSONの参照先はそのフォルダー内に収めます。今回の表示機能はCubism 3以降、PNGテクスチャ（最大8192ピクセル）に対応します。

読み込み後は左右・上下の顔向き、両目の閉じ方、口の開閉、髪と輪の揺れ、背景透明、拡大・縮小、本体最小化中の操作、繰り返し読み込みと終了を確認してください。実際のモデル表示は公式Haruサンプルで検証しましたが、凛音エルのモデル品質確認を終えたことにはなりません。

表示ライブラリは非公式Pythonラッパー [live2d-py](https://github.com/EasyLive2D/live2d-py) 1.0.0です。CubismのCoreとモデルの利用条件は、[Live2DのSDK案内](https://www.live2d.com/sdk/about/)と各素材の利用条件を確認してください。Haruサンプルは検証環境だけに保持し、ESIの配布物には含めません。
