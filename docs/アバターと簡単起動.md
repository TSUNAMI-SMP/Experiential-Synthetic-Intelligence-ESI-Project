# ESI-01の新しい起動方法とアバター

すでにESI-01を使えている方向けの説明です。初めて導入する場合は[はじめての導入](はじめての導入.md)でPythonとAIデータを準備してください。今回の更新で、毎回のコマンド入力は不要になります。

## 今あるESI-01を更新する

1. ESI-01の画面を閉じます。
2. [GitHubから更新版をダウンロード](https://github.com/TSUNAMI-SMP/Experiential-Synthetic-Intelligence-ESI-Project/archive/refs/heads/main.zip)します。ZIPを右クリックして「すべて展開」を選びます。
3. 展開した中の、`README.md`が見えるフォルダーを開きます。そこにある `src`、`scripts`、`docs`、`tests` の4つのフォルダー、`pyproject.toml`、`requirements.lock`、`requirements-live2d.lock`、`ESI-01を起動.cmd`、`初回準備・更新.cmd` を、今まで使っていたESI-01フォルダーへコピーします。同じ名前は上書きします。
4. 今までのフォルダーにある **「初回準備・更新.cmd」をダブルクリック**します。準備が終わるまで待ち、最後にキーを押して閉じます。この操作は更新したときに1回だけ必要です。
5. **「ESI-01を起動.cmd」をダブルクリック**します。

`data`には経験のセーブ、`models`にはAIデータ、`llama`には言語ソフト、`.venv`にはPythonの準備が入っています。この4つは今のものをそのまま使います。セーブを消したり、AIデータを再ダウンロードしたりする必要はありません。設定ファイルも今の `config/windows.toml` を使えます。

`.cmd`は、Windowsで起動操作をまとめたファイルです。今回はこれを使います。Windows専用の単体EXEは今回作成していません。

## 毎回の起動

「ESI-01を起動.cmd」を開くと、起動準備の小さい画面が出ます。言語ソフトとAivisSpeechにつながると本体が開きます。前回開いていたセーブを引き継ぎ、**停止中から**始まります。

言語ソフトは、今ある `llama/llama-server.exe` とQwen3-4Bのデータを使って自動起動します。すでに同じモデルで動いている場合は、それを利用します。

AivisSpeechは、標準的なインストール場所から探します。見つからないときは、普段どおりAivisSpeechを開いて「再試行」を押せます。次回から自動起動したければ、「AivisSpeechを選ぶ」でインストール先の `AivisSpeech.exe` を一度指定します。凛音エルが未導入なら、ダウンロード済みの指定版AIVMXを確認して導入します。

接続に失敗した場合は、原因が起動画面に表示されます。「画面だけ開く」でセーブや設定を確認でき、「ログを開く」で詳しい記録を見られます。前回のセーブが見つからない場合は「セーブを選ぶ」で指定してください。別の空のセーブを自動作成して置き換えることはしません。

終了すると、自動起動した言語ソフトも終了します。先に自分で起動していた言語ソフトとAivisSpeechはそのままです。

## アバターを表示する

本体上部の **「最前面にアバターを表示」** にチェックを入れます。

| したいこと | 操作 |
| --- | --- |
| 位置を変える | 立ち絵を押したままドラッグ |
| 大きく／小さくする | 下の「＋」「−」 |
| ESIを動かす／止める | 下の「開始」「停止」 |
| マイクを使う／止める | 開始後、下の「マイクON／OFF」 |
| 本体の画面を戻す | 下の「本体」 |
| アバターを隠す | 下の「×」。本体の処理は続きます |

**本体を最小化しても、アバターと操作ボタンは残ります。** アバター下には現在の動作とアイコンを表示します。位置と大きさは保存します。本体の画面を閉じると、アバターも閉じてESIを終了します。

この表示用立ち絵は、いただいた画像を基に背景を透過したものです。輪郭に小さな補正差がある場合があります。現在の同梱画像は静止画で、Live2Dの完成モデルではありません。

## セーブを開く

本体の **「セーブを開く」** を押して、`data`の中の `.sqlite3` ファイルを選びます。たとえば `esi-01.sqlite3` が通常のセーブです。`.sqlite3-wal`や`.sqlite3-shm`は読み込みボタンで選ぶファイルではありません。

処理中でも操作できます。現在の状態を保存して停止し、選んだセーブの経験・学習状態・設定を読み込みます。「開始」を押すと続きを動かします。次回のダブルクリック起動でも、そのセーブを開きます。読み込めないファイルだった場合は現在のセーブを保持します。

「保存」は現在のセーブへの記録です。「詳しい観察」の「実験分岐」は、別のセーブにコピーして実験条件を分けるための操作です。

## アイコンの見方

大きいアイコンと文章で現在の動作を表示し、「入力 → 聞き取り → 検討 → 発声」の4つの枠では進行中の枠が明るくなります。月のアイコンは「休む」、時計は「待つ」、頭のアイコンは「検討する」、スピーカーは発声の処理です。実際に選ばれた行動や処理段階を示します。

「休む」「検討する」を選んだ場合は、聞き取りに成功していても発声しないことがあります。アバターを有効にしても、行動の評価規則や学習方法は変わりません。

## 本格的なLive2Dの状況

**凛音エルの本格的なLive2Dモデルはまだ完成していません。** 現在用意したのは、表示用の透過立ち絵と、[パーツ分けの下書き](avatar-materials/rion-el-parts-draft.png)です。この下書きは生成処理で隠れた部分などを補った1枚の部品表であり、元の絵をそのまま切り抜いたPSDでも、動きを設定したモデルでもありません。

本体側には、完成したLive2Dモデルを表示する機能を用意しました。「Live2Dモデルを選ぶ」で `.model3.json` を指定します。同じフォルダーの `.moc3`、画像、動きのファイルも必要なので、モデルのフォルダー全体を置いてください。「立ち絵に戻す」で元の表示に戻せます。

モデルに対応する設定があれば、瞬き、呼吸、視線追従、物理演算を表示します。実際の音声再生中に `ParamMouthOpenY` を動かします。これは発声中を示す簡易的な口の動きで、音素や音量に厳密に合わせる処理はまだありません。

残る制作は、[Live2D Cubism Editor](https://www.live2d.com/cubism/download/editor/)をWindowsまたはMacで使い、部品を清書してレイヤー付きPSDにまとめ、顔の向き・瞬き・口・髪などの変形と動きを設定して、実行用モデルを書き出す工程です。このクラウドはLinuxで、Cubism Editorによる制作・書き出しは実行できていません。[制作の引き継ぎ資料](avatar-materials/README.md)に部品と設定の目安をまとめています。
