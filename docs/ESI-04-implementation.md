# ESI-04 実装・検証記録

状態: ESI-04（0.4.0）の実装とクラウドでの動作検証を完了。基点はESI-03の7d459ec。WindowsのGPU・物理音声機器・UI Automationによる実機の結果は、利用者のPCで確認する。

## 実装する内容

1. 会話の意図・提案・自己状態・欲求・興味・質問への回答を区別し、単語だけで身体報告へ分岐しない。
2. 直前の質問と自然な音声・文字の回答を対応付ける。曖昧なら確認し、沈黙は未観測として保留する。ボタン操作を必須としない。
3. 固定周期の質問を廃し、欲求・関心・出来事・相手の状態・競合する行動から発話を選ぶ。同じ問いを無根拠に反復しない。
4. お菓子・家具・パソコン等の物体を位置・個数・状態付きで配置・移動・撤去。自然文と画面の双方に対応する。
5. ESIが見る・近づく・調べる・使う・食べる・休む行動を選び、実際の状態変化から記憶・好みを更新する。
6. 会話のない間に経験を整理し、矛盾・未解決の疑問・計画・調査・操作技能の再検討を進める。生成した推測を観測済みの事実や正解にしない。
7. 内部状態と意図から表情・視線・簡単なポーズを選ぶ。必要なCubismの作画・リギングを含める。カーソル追従は任意。
8. 2Dアバターにクリックできる吹き出しを付け、関心・検討候補・選択理由・結果の短い要約を表示する。
9. 画面閲覧を許可した際に選択画面を観察し、視覚モデルと画面の文字・要素を利用して説明と対応付ける。
10. PC操作を許可したセッションでマウス・キーボード操作を行い、操作前後の実画面から結果を確認する。
11. 利用者の実演と説明を時系列で記録し、画面条件・対象・操作・結果を技能として覚え、似た状況で再利用・失敗修正する。
12. PC操作許可時にアバターの位置を把握し、注意の対象や操作対象を踏まえて自分で移動する。

## 保存と検証

- ESI-03から読み取り専用コピーで移行し、元セーブ・履歴・キャラクター・知識を保持する。
- 外部操作の権限は再起動後に自動復活させず、途中だった操作も自動再実行しない。
- 画面・操作実演は選択・許可された範囲をローカルで扱い、診断へ画面や本文を混入させない。
- 掲載された利用者の会話ログを連続した回帰ケースにする。
- 模擬結果だけで完成としない。実言語・視覚モデル、実スクリーン取得と操作、ネイティブ描画とCubism再出力、保存・復旧・既存版互換を検証する。
- 実機Windows・GPU・物理音声とクラウドでの検証は区別する。
- 基礎モデルの重みの自動訓練は今回の範囲に含めず、経験・記憶・技能・判断の変化を測る。

## 実装した構成

| 項目 | 結果 |
| --- | --- |
| 会話 | 提案・体験談・居心地・欲求・興味・身体の数値・画面・物体の操作を分ける。モデルの誤った自己意図で利用者の体験談を置き換えない。 |
| 質問と返答 | 自然な返答を質問へ対応付け、曖昧なら確認。確認への「いいえ」は誤った対応を解除する。沈黙は未観測、古い質問への無関係な「はい」は回答にしない。 |
| 自律性 | 欲求・関心・在席・競合する行動で質問を選ぶ。質問の固定周期を使用せず、同じ証拠からの反復を抑える。 |
| 部屋 | 物体の位置・個数・机との関係・発見・使用・消費を保存する。家具を避ける経路、届く高さ、身体と家具の重なりを確認する。置き直した休む場所や水を実際に参照する。 |
| 会話のない間の活動 | 物を発見・調査・使用・消費・遊ぶ。信念の出典や食い違いを見直し、関心・調査・許可された実演の練習・画面観察を選ぶ。生成した案を新しい事実として保存しない。 |
| アバター | 独立した両腕、眉の上下・傾き、閉じた口の表情をCubismで追加。感情・意図・注意の方向から穏やかに動かす。標準ではカーソルへ追従しない。 |
| 吹き出し | クリックで活動・関心・比べた行動・選択の短い理由・結果を表示。観察・推測・予定を区別する。 |
| 画面 | 固定した実画面とハッシュを視覚モデルへ渡す。見えた文字と対象を記録し、利用者の説明と対応付ける。会話からの質問も読み取り完了を待って返答する。 |
| PC操作 | 新しい画面と現在のウィンドウ・入力先・権限を確認して入力。許可解除や新しい会話で中止する。「一度だけ」のクリックを重ねず、同じ入力を無条件に反復しない。 |
| 実演 | 記録中だけ実際の操作を収集し、操作前後の画面、要素の識別情報または画像の目印で技能を保存。名前による再現、練習の個別許可、削除に対応。読み落としや曖昧な目印では停止する。 |
| 自主移動 | PC操作の許可中に、注意を向けた対象を隠しにくい位置を選ぶ。手で移動した位置を尊重し、停止・許可解除では移動も止める。 |
| 保存と起動 | ESI-03を一貫したコピーで移行。元セーブ・アーカイブ・履歴を保持する。画面・技能はセーブごとの別フォルダー。権限と途中の実PC操作は再起動で復活しない。 |

会話はQwen3-4B、画像の読み取りはQwen3-VL-2B-Instructの指定版をローカルで使う。視覚用のモデルとプロジェクターは合計1,552,463,168バイト。元の会話・聞き取り・音声データを使い続ける。重みやCUDAコードの無制限な自己改造、任意の操作の完全な習得、動画の音声や全フレームの理解は実装範囲に含めない。
