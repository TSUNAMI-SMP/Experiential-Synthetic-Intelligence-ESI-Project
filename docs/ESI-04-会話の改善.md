# ESI-04 0.4.8 — 自由な発話・相づち・処理の声掛け・長考

質問・お願いの専用システムを廃止しました。ESIが自分から伝える感想・独り言・希望・質問は、普段の会話欄と音声に出ます。「話しかける」「あとで」「今回は断る」の回答カードは表示しません。

## 更新する

1. ESIを終了します。
2. GitHubから更新版ZIPを取得し、展開したフォルダーの内側を、これまで使っていたESIフォルダーへコピーします。`data`・`models`・既存のPython環境・AivisSpeechは残してください。別の空フォルダーでは元のセーブが開かれません。
3. `ESI-04を起動.cmd` を開き、上部の版が **0.4.8** になっていることを確認します。AIデータの再ダウンロードやMODの入れ替えは不要です。ZIP版の更新で `git pull` は使いません。

旧版の質問・経験の記録は消しません。古い回答待ちや再生途中の発言を再開しない形で移行します。名前・性格・敬語の設定・知識・訂正履歴・過去の会話を保持します。Minecraftプラグインは引き続き一時無効です。

## 普通に話す

ESIの質問にも、独り言にも、普通にマイクか入力欄で返せます。質問IDや回答ボタンによる待ち受けは使いません。直前の自分と相手の発言を同じ履歴として読みます。無回答や話題の変更を承諾・拒否として採点せず、発話だけで知識や成長の報酬を作りません。

「青です」「そうなんですね」のような短い返答に、長い説明を必ず付けることはしません。挨拶や単純な感謝・相づちはモデルの長い検討を省きます。意味の判断が必要な内容はモデルが文脈を読み、短く答えることもできます。「一言だけで」「簡潔に」と指定できます。具体的な質問への回答を、ただの相づちで済ませない確認は維持しています。

画像で報告された「質問文について、もっと詳しく教えて」という再帰的な質問を防ぎました。生成した質問文を新しい関心の対象へ変換して、もう一度質問する経路を止めています。オウム返しや途中で切れた返答も発声前に確認します。

## 自分から話す

「性格・欲求・成長・探索」→「関心・成長目標」で、次を選びます。

- **自分のタイミングで話す（感想・独り言・質問など）**：自発的な発話のON/OFF。
- **会話がない間も、体験を見直して活動する**：会話のない間の検討を有効にする。
- **時間のかかる処理では、実際の状況を短く声で伝える**：処理の声掛けだけを個別にON/OFF。

発話は一定の秒数ごとに送る方式ではありません。新しい会話・観察・体験、関心、欲求の変化、相手の都合から、話すか別の活動をするかを選びます。自分の感想を伝えることも、話さず見直す・休むこともできます。同じ状況だけで発話を無限に生成したり、同じ内容を繰り返したりしないようにしています。

「今は忙しい」「後で」「話しかけないで」を受け取ります。返答を強制する専用の依頼、回答期限、返事がないことへの減点はありません。身体の自発的な活動と、自分から話す設定は分かれています。

自発的な発言は会話欄と「会話履歴・セーブ」に残ります。アバターの活動吹き出しからも最近の発言を見られます。発声中の吹き出しには、その時の発言を表示します。

## 考えている間の声掛け

実際に時間がかかっている処理に合わせて、短く声で伝えます。

| 実際の処理 | 声掛けの例 |
| --- | --- |
| 発言を受けて回答を構成 | 情報を整理しています。 |
| 複数条件の比較・計画等の追加検討 | 少し時間をかけて考えます。 |
| 許可されたWeb検索を開始 | 検索しています。 |
| 許可された資料の読み取り | 資料を読んでいます。 |
| 許可された画面の観察 | 画面を確認しています。 |

すぐ終わる処理では声掛けを省き、同じ返答で何度も報告しません。実行していない検索・画面確認を、言葉だけで行ったことにはしません。検索・画面・PCの許可や対象範囲は従来どおり必要です。

声掛けと返答は同時に再生せず、音声に合わせた口パクを使います。新しい入力や停止で中断できます。任意の声掛けの音声生成が失敗しても、本来の返答文・返答の音声を一緒に捨てません。処理の一言は状態説明として記録し、新しい知識や本人の教示にはしません。

## 必要なときに長く考える

複数条件の比較・計画や、「じっくり考えて」「時間をかけて検討して」と頼んだ相談では、論点・条件・未確認事項を整理する工程と、返答の出力枠を増やします。単純な返事では省きます。途中で新しい発言を送ったり停止したりできます。

基礎モデルは従来のQwen3-4B Q4_K_Mです。追加検討はモデルの交換・訓練や検索の代わりではなく、正しさの保証でもありません。実試験でも比較条件の取り違えは残っています。内部の詳細な思考の書き起こしを音読する機能ではなく、実際の処理の短い説明を話します。応答時間はPCのGPU・モデル・入力の長さに依存します。

## 試す例

- 「おはよう」「それについて教えてくれてありがとう」→短い挨拶や感謝の返答。勝手な質問や体調の報告を付けない。
- ESIが「好きな色は？」と話した後、「青です。一言だけ返してください」→文脈に合う短い返答。
- 「水はなぜ凍るのですか？」→相づちだけで終えず、質問へ答える。
- 「静かな曲です。タイトルは『夢』です。どう感じますか？」→相手の質問の丸写しや「質問文について教えて」の反復をしない。音を聴いていないことと、説明からの感想を区別する。
- 「毎日20分勉強する案と週末に140分勉強する案を、平日は忙しいという条件も含めてじっくり比較して」→声掛けと、条件を踏まえた詳しい返答。
- 会話を止め、部屋で新しい物を使う機会を作る→質問に限らない発話や、別の活動を選ぶ様子を確認する。毎回話すことを強制する設定ではない。

一般知識の利用、敬語／やわらかい敬語、控えめな不安・焦り・怒り、誤った教えと訂正の出典を保存する方針は維持しています。クラウドでの検証範囲は [実装・検証記録](ESI-04-implementation.md) を参照してください。利用者のWindowsのGPU・物理マイク・スピーカーは、こちらのクラウドから直接検査できません。
