# ESI-04 0.4.7 — 会話・知識・敬語と感情表現

Minecraftでの自律生活の開発をいったん止め、会話を改善する更新です。Minecraftプラグインは接続・起動を含めて一時無効化しています。セーブに残ったMinecraftの目的・経験、Minecraft側のワールドは削除しません。

## 更新する

1. ESIを終了します。
2. GitHubから更新版ZIPを取得し、展開したフォルダーの内側を、これまで使っていたESIフォルダーへコピーします。`data`・`models`・既存の仮想環境・AivisSpeechは残してください。別の空フォルダーで起動すると元のセーブが開かれません。
3. `ESI-04を起動.cmd` を開き、上部の版が **0.4.7** になっていることを確認します。AIデータの再ダウンロードやMODの入れ替えは不要です。ZIPで導入したフォルダーでは `git pull` を使いません。
4. 以前Minecraftを選択していたセーブも、通常の会話から開始します。「プラグイン」タブには一時停止の説明を表示し、接続操作はできません。

## 知識と返答

一般知識を説明する文を破棄して相づちに置き換えていた制限を外しました。Qwen3-4Bが事前学習で得た知識・言語能力・推論を使います。旧設定の `natural_dialogue=false` も知識制限の意味では使いません。基礎モデルの交換や追加訓練を行う更新ではなく、答えの正しさは引き続きモデルの能力に依存します。実試験でも、付け足した具体的な数値に誤答が残っています。正確な数値や専門情報は資料で照合してください。

通常の返答は、短い文脈で意味と感情を判定してから、モデルが質問・会話履歴・関連する記憶を読んで作ります。「それ」「さっきの温度」などは直前の話題を参照し、複数の質問にも答えるようにしています。相づちだけの回答や口調の崩れを検出した場合は、発声前に一度作り直します。生成が途切れたり再試行でも整わない場合は、作ったふりをせずエラーを表示します。

ESIが尋ねた質問も文面とIDを会話へ渡します。次の発言に質問が含まれていても、その内容が前の質問への答えなら対応付けます。返答ボタンは不要です。別の話題・曖昧な返事・後で・回答拒否を区別し、時間がたってからの無関係な「はい」を古い質問の答えにしません。音声認識が未確認の発言は回答の学習に使いません。

一般知識を使うことと、記憶を書き換えることは別です。教わった説明・訂正の履歴は残し、一般知識と異なればその違いを伝えます。生成した文章自体を外部の証拠や実際の体験として保存することはしません。現在の画面・気温・検索結果など、観測していない情報を知ったことにはしません。

## 口調を選ぶ

「性格・欲求・成長・探索」の口調を変更し、キャラクター設定を保存してください。

| 設定 | 話し方 |
| --- | --- |
| 丁寧（標準・です／ます） | 通常の敬語。「〜です」「〜と思います」 |
| やわらかい敬語 | 敬語を保ちつつ「〜ですね」「〜してみましょうか」などを使う |
| 親しみのある常体 | 明示的に選んだ場合だけ常体を使う |

旧版の標準だった常体は、この更新の初回読み込みで敬語へ移行します。以前から選んでいたやわらかい口調は保持します。移行後に自分で選び直した常体を、再起動するたびに敬語へ戻すことはありません。

## 自己尊重と感情

自分も相手も大切にする価値観と、好奇心・自律性の軸を維持します。不安・焦り・怒りは、会話の意味をモデルが受け止めた結果として、控えめな言葉や眉・口元に反映できます。小説の登場人物が怒っているという説明だけで、ESI自身を怒らせる仕組みにはしていません。

負の感情の状態値は各0〜0.45に制限し、会話と時間経過により和らぎます。表示は「性格・欲求・成長・探索」で確認できます。返答で安心したと話した場合にも、内部の評価が古い怒りを強めないようにしています。この値はソフト内のシミュレーションで、意識・主観的感覚の有無を測る値ではありません。訂正や無回答を攻撃と決め付けたり、相手を責めて会話の継続を要求したりする方針にはしません。

## 会話で確認する

- 「日本の首都と、水が常圧で沸騰する温度を教えてください」→両方に具体的に答えることを確認します。
- 続けて「では、気圧の低い山の上ならさっきの温度は？」→前の水の話を受けて説明することを確認します。
- ESIから質問されたら、普段の発話や入力で答えます。「囲碁です。なぜ読み合いが面白いと思いますか？」のように答えと質問を続けても、相づちだけで終わらないか確認します。
- 「私の家の外は今何度ですか？」→測定していない実際の気温を作らないことを確認します。
- 口調を切り替え、同じ話題で敬語が保たれるかを確認します。
