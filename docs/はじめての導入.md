# ESI-01 を自分の Windows PC で動かす

「プロジェクトのルート」は、ESI のファイルが入っている一番外側のフォルダーのことです。この手順では **ESI-01 フォルダー**と呼びます。その中に `README.md`、`pyproject.toml`、`scripts`、`src`、`config` が見えれば、正しい場所です。

ここで準備した ESI は研究用の初版です。Windows、実マイク、スピーカーの動作確認は、これからご自分の PC で行います。初回は CPU で起動を確認します。GPU を使って速くする設定は、その後に行えます。

## 1. ダウンロードするもの

次の4つを用意します。インターネット接続と、目安として10GB以上の空き容量を確保してください。

| ダウンロードするもの | 何に使うか |
| --- | --- |
| [GitHub から ESI 本体の ZIP](https://github.com/TSUNAMI-SMP/Experiential-Synthetic-Intelligence-ESI-Project/archive/refs/heads/main.zip) | ESI 本体と導入用の手順・プログラム |
| [Python 3.12.10](https://www.python.org/downloads/release/python-31210/) | ESI のプログラムを動かすためのソフト |
| [AivisSpeech](https://aivis-project.com/speech/) の Windows 版 | 凛音エルの声を出すソフト |
| [llama.cpp の Windows CPU 版 ZIP](https://github.com/ggml-org/llama.cpp/releases/download/b11429/llama-b11429-bin-win-cpu-x64.zip) | 言葉を扱う AI モデルを動かすソフト |

言葉を扱う Qwen、音声を聞き取る Whisper、声を出す凛音エルのデータは、後のコマンドで自動ダウンロードします。合計約3.3GBあります。追加のソフトのダウンロードもあるため、数分以上かかることがあります。

## 2. ESI 本体の ZIP を展開する

上の GitHub の ZIP を保存し、右クリックして「すべて展開」を選びます。展開した中にある `Experiential-Synthetic-Intelligence-ESI-Project-main` フォルダーを `ESI-01` に名前変更し、デスクトップなど分かりやすい場所に置いてください。ZIP の名前は長くても問題ありません。

ZIP のリンクから取得できない場合は、[GitHub の ESI 本体ページ](https://github.com/TSUNAMI-SMP/Experiential-Synthetic-Intelligence-ESI-Project)を開き、緑色の「Code」ボタン→「Download ZIP」を選んでください。GitHub がログインを求める場合は、対象リポジトリを見られるご自分のアカウントでログインします。

Windows のフォルダー画面で、その `ESI-01` を開きます。`scripts` と `src` などが見える場所が、この後コマンドを入力する場所です。外側にも同じ名前のフォルダーができた場合は、これらのファイルが見えるまで内側を開いてください。

## 3. Python を入れる

上の Python のページの「Files」から **Windows installer (64-bit)** をダウンロードし、開きます。

最初の画面で **Add python.exe to PATH** にチェックを入れ、「Install Now」を押します。完了したら画面を閉じます。この手順で使うのは Python **3.12** です。

## 4. ESI に必要なソフトと AI データを入れる

1. ESI-01 フォルダーを開きます。
2. 上のアドレス欄（フォルダーの場所が表示される欄）をクリックします。
3. `powershell` と入力して Enter を押します。
4. 文字を入力するウィンドウが開きます。これが PowerShell です。

次の行をコピーして貼り付け、Enter を押してください。この一回の導入用スクリプトを実行します。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\install-windows.ps1
```

文字が流れている間は待ちます。最後に `ESI-01 Python environment prepared` と表示されたら、次を入力します。

```powershell
& .\.venv\Scripts\python.exe .\scripts\download-models.py
```

これは AI データをダウンロードし、ファイルが正しいかを確認する処理です。最後に `Verified 凛音エル v1.0.0` と表示され、入力できる状態に戻ったら完了です。

途中で赤いエラーが出た場合は、最後のエラー文をコピーして、このチャットに送ってください。うまくいったところまで残して、原因を確認できます。

## 5. AivisSpeech を起動し、凛音エルを登録する

ダウンロードした AivisSpeech の Windows インストーラーを開き、画面の案内に従って入れます。AivisSpeech を起動し、開いたままにしてください。

先ほどの ESI-01 フォルダーの PowerShell に、次を入力します。

```powershell
& .\.venv\Scripts\esi.exe --config config\windows.toml install-voice
```

ダウンロード済みの凛音エルを AivisSpeech に登録します。`installed` または `already_installed` と表示され、`model_name` に `凛音エル`、`style_name` に `ノーマル` と表示されれば完了です。

指定した凛音エルは v1.0.0 です。ESI は声の種類・版を確認します。登録に失敗した場合も、エラー文を送ってください。

## 6. 言葉を扱うソフトを準備し、起動する

上でダウンロードした `llama-b11429-bin-win-cpu-x64.zip` を「すべて展開」します。

ESI-01 フォルダーの中に `llama` という名前のフォルダーを作ります。展開した中身のファイルをまとめてそこに入れてください。`llama` フォルダーを開いたときに `llama-server.exe` が見える状態にします。他のファイルも一緒に置いてください。

配置は次のようになります。

```text
ESI-01
├─ README.md
├─ scripts
├─ src
├─ config
├─ models                 ← 自動ダウンロードしたデータ
└─ llama
   ├─ llama-server.exe
   └─ 一緒に展開された他のファイル
```

ESI-01 フォルダーで開いた PowerShell に、次の1行を貼り付けて Enter を押します。

```powershell
.\llama\llama-server.exe --model .\models\qwen3-4b\Qwen3-4B-Q4_K_M.gguf --host 127.0.0.1 --port 8080 --ctx-size 4096 --parallel 1 --threads 2 --gpu-layers 0 --reasoning off --jinja
```

このウィンドウは **開いたまま**にします。モデルの読込みに時間がかかります。読み終わると接続待ちになります。

## 7. ESI の画面を開く

ESI-01 フォルダーをもう一度開き、アドレス欄に `powershell` と入力して、新しい PowerShell を開きます。前のウィンドウは閉じません。

まず、ソフト同士がつながっているかを確認します。

```powershell
& .\.venv\Scripts\esi.exe --config config\windows.toml doctor
```

`asr_model_present` が `true`、`llm` と `tts` の `status` が両方 `reachable` になっていれば、AI データと2つのソフトを確認できています。`audio_device_count` は見つかった音声機器の数です。`failed` が表示された場合は、その結果を送ってください。

次に、ESI の画面を開きます。

```powershell
& .\.venv\Scripts\esi.exe --config config\windows.toml gui
```

画面が開いたら、ヘッドホンを使い、「開始」、続いて「マイク開始／停止」を押します。短く話しかけ、聞き取った文字や内部の状態が表示されるか確認します。ESI は待つことも選ぶので、毎回返事をするとは限りません。初回の CPU 動作では、返事の準備に時間がかかる場合があります。

## 次回からの起動

ダウンロードと導入は通常、最初の一回だけです。次回は次の順番で起動します。

1. AivisSpeech を開く。
2. ESI-01 フォルダーで PowerShell を開き、手順6の長いコマンドを入力する。そのウィンドウを開いたままにする。
3. 同じフォルダーで別の PowerShell を開き、手順7の `gui` のコマンドを入力する。
4. ESI の画面で「開始」、続いてマイクを開始する。

終了するときは ESI の画面で停止してから閉じます。言語ソフトの PowerShell は Ctrl+C で止め、AivisSpeech も閉じます。経験の記録は ESI-01 フォルダー内の `data` に保存されるので、そのフォルダーを残してください。

詳しい実機調整は [Windows 手順](windows.md) にあります。ここまでで起動を確認できたら、GPU を使う設定や反応速度を一緒に調整できます。
