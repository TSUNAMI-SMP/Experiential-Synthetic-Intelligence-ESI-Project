# 凛音エル / ESI-04用モデル

ESI-03の元絵・目・眉・髪・五本指を引き継ぎ、Cubism Editor 5.3.04 FREEで表情と腕を追加したモデル。SDK 4.2向け、パラメーター29個、ArtMesh 29個、2048×2048テクスチャ1枚。

- `ParamArmLZ` / `ParamArmRZ`: 画面左／右の腕。-10〜10。正方向は体側へ5度、負方向は外側へ1度。指先が表示範囲から切れない範囲に制限した。
- `ParamBrowLY` / `ParamBrowRY`: 眉の上下。`ParamBrowLAngle` / `ParamBrowRAngle`: 眉の傾き。各-1〜1、左右別に変形する。
- `ParamMouthForm`: 閉じた口の穏やかな笑顔／困り顔。`ParamMouthOpenY`: 発声時の口。
- 頭・体・呼吸・後ろ髪・輪は従来のリグを使用する。独立した眼球の追視、指の関節、手を頭上まで上げる動作は含まない。
- まばたきは元絵の開眼／閉眼を切り替える。中間に両方の絵を混ぜず、目のメッシュを拡大縮小しない。ESIのレンダラー側の切り替え処理と組み合わせて使う。

通常時の目・眉はESI-03と同じ画素を使用する。テクスチャ自体はESI-03と同一で、再生成画像への置き換えはしていない。首は顔の後ろ、後ろ髪は顔の後ろ、襟は首より前、眉は前髪より前の関係を維持する。

編集元: `docs/avatar-materials/esi04-source-work/rinne-el-rigged-working.cmo3`。
編集元を閉じて開き直した後の5ファイルの再出力はバイト単位で一致した。
ネイティブ描画の検証は `scripts/validate-rinne-esi04.py`。クラウドのX11/OpenGLでの確認であり、利用者のWindows・物理音声出力の確認を意味しない。
