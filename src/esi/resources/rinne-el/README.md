# 凛音エルの実行用モデル

Cubism Editor 5.3.04 FREEで制作し、SDK4.2向けに書き出したMOC3・model3.json・物理演算・2048×2048の透過テクスチャです。PNGだけを動かす表示ではありません。原画と編集用PSD/CMO3は `docs/avatar-materials/esi02-source-work/` に保持しています。

表示部品は胴と手足、肌、髪、輪、左右それぞれの開いた目と閉じた目、口の9個です。瞬きは開閉2枚の目を使います。ESI-02では開度を開眼・閉眼へ切り替え、途中で2枚が重なって虹彩とまぶたが二重になるのを防ぎます。連続したまぶたの形状変形ではありません。口は縦方向の変形で開閉します。呼吸は上部のベジェ制御点を動かす変形、頭のX/Yは小さい追従移動、Zは首を軸にした傾きです。髪と輪は独立した回転器へ物理演算を適用します。広い顔向きの遠近作画や、手足の独立した動きはこのモデルにありません。

新しい表示設定ではこのモデルを使います。既存の静止画の選択やカスタムモデルの選択は保持します。「凛音エル」で標準モデル、「立ち絵に戻る」で静止画へ切り替えられます。

両手は親指を含めて5本に修正し、輪郭に沿うメッシュを再生成しました。開眼と閉眼はそれぞれ同じ素材を反転し、左右の形・高さを揃えています。肌と首の描画順は450、胴と襟は500とし、首の根元が襟の手前へ出るのを防ぎます。髪による眉の隠れ方には髪型による差があります。

Linuxの実際のCubism Coreによる透過描画、瞬き途中を含む13状態での形状と表示、音量による口の形状変化、瞬き、呼吸、再読込み、最小化、終了を検証しました。保存したCMO3を開き直し、実行用5ファイルがすべてバイト単位で再生成できることも確認済みです。Windowsでの起動成功は利用者から報告されています。GPU/実マイク・スピーカーの確認は別途必要です。モデル素材の一覧とハッシュは `manifest.json`。Editor本体・インストーラー・検証用Haruは含めていません。
