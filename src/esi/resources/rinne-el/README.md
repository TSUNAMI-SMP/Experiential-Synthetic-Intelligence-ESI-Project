# 凛音エルの実行用モデル

Cubism Editor 5.3.04 FREEで制作し、SDK4.2向けに書き出したMOC3・model3.json・物理演算・2048×2048の透過テクスチャです。編集元のPSD・CMO3は `docs/avatar-materials/esi02-source-work/` に保持しています。

表示部品は26個です。通常の目・まつげ・眉・口・髪・輪には原画の画素を使い、原画の自然な左右差を保ちます。後ろ髪は6部品で顔の後ろへ置き、前髪・眉・顔・首・襟を分けています。胴500、首590、顔600、耳610、襟650、開口801、前髪900、開眼910、閉眼920、眉950の描画順です。通常時は開口用の口を隠して原画の口を表示し、発声時は肌の小さな部品で通常の口の線を隠して縦方向に開口します。

閉眼は原画を参照した別の作画です。ESI-02では開眼・閉眼を切り替え、途中で虹彩とまぶたを二重に重ねません。連続したまぶたの形状変形ではありません。閉眼の見えるまつげ幅は開眼を超えず、左右差は比較画像で2px以内です。開眼→閉眼→再開眼で最初と最後の画像が一致することも検査します。比較画像と測定方法は `docs/avatar-materials/esi02-face-comparison/`。

両手は既存の5本指の修正を保持します。呼吸・身体・頭の小さい追従移動と傾き、後ろ髪と輪の揺れを使います。広い顔向きの遠近作画や手足の独立した動きはこのモデルにありません。

新しい表示設定ではこのモデルを使います。既存の静止画・カスタムモデルの選択は保持します。「凛音エル」で標準モデル、「立ち絵に戻る」で静止画へ切り替えられます。モデル素材の一覧とハッシュは `manifest.json`。Editor本体・インストーラー・検証用Haruは含めていません。

Linuxのネイティブ描画で確認した結果と、Windowsの実機確認を区別しています。Windowsでの起動成功は利用者から報告されていますが、今回の修正後のGPU・実マイク・スピーカー・表示は再確認が必要です。
