# 凛音エルの実行用モデル

Cubism Editor 5.3.04 FREEで制作し、SDK4.2向けに書き出したMOC3・model3.json・物理演算・2048×2048の透過テクスチャです。PNGだけを動かす表示ではありません。原画と編集用PSD/CMO3は `docs/avatar-materials/esi02-source-work/` に保持しています。

表示部品は胴と手足、肌、髪、輪、左右それぞれの開いた目と閉じた目、口の9個です。瞬きは開閉する目の不透明度を補間し、口は縦方向の変形で開閉します。呼吸は上部のベジェ制御点を動かす変形、頭のX/Yは小さい追従移動、Zは首を軸にした傾きです。髪と輪は独立した回転器へ物理演算を適用します。広い顔向きの遠近作画や、手足の独立した動きはこのモデルにありません。

新しい表示設定ではこのモデルを使います。既存の静止画の選択やカスタムモデルの選択は保持します。「凛音エル」で標準モデル、「立ち絵に戻る」で静止画へ切り替えられます。

Linuxの実際のCubism Coreによる透過描画、11状態での形状と不透明度、音量による口の形状変化、瞬き、呼吸、再読込み、終了を検証しました。Windows/GPU/実マイク・スピーカーの確認は別途必要です。モデル素材の一覧とハッシュは `manifest.json`。Editor本体・インストーラー・検証用Haruは含めていません。
